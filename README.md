## 📌 About the Project

**MyTradingBot** is a personal experimental project focused on exploring algorithmic trading, working with financial data, and testing automated strategies in Python. 

The goal of the project is testing and development in a controlled environment (sandbox/paper trading) with no commercial ambitions.

## ⚙️ Key Features

* **Modular Structure:** Separated configuration, data management, and strategy logic.
* **Configurable Environment:** Easy adjustment of parameters via configuration files.
* **Research Focus:** Suitable for backtesting and historical data analysis.
